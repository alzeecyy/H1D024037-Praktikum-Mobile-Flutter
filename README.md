📝 Tugas Pertemuan 1

Deskripsi Teknis & Non-Teknis:

Non-Teknis:  
Mengenal dasar bahasa pemrograman Dart yang digunakan sebagai bahasa utama pada Flutter. Pembahasan mencakup keunggulan Dart dalam pengembangan aplikasi multiplatform (dapat berjalan di Android, iOS, dan web dengan satu codebase), konsep dasar pemrograman berorientasi objek (OOP), alur proses asinkronus, serta penanganan error pada program.

Teknis:  
- Mencoba langsung penulisan dan eksekusi kode Dart secara online melalui [DartPad](https://dartpad.dev), diawali dengan program sederhana "Hello World".
- Mempelajari ragam tipe data dasar seperti `int`, `double`, `String`, `bool`, dan variabel `var`, serta mencoba operasi perhitungan matematika dan logika perbandingan.
- Mengatur alur logika program menggunakan struktur percabangan (`if-else`) dan perulangan (`for` serta `while` loop).
- Membuat fungsi mandiri, menerapkan konsep dasar OOP (membuat *Class*, inisialisasi *Object*, atribut, dan *method*), serta mencoba *import* library bawaan seperti `dart:math`.
- Menangani error pada saat program berjalan menggunakan blok `try-catch` agar aplikasi tidak terhenti tiba-tiba (*crash*), serta mencoba proses asinkronus menggunakan `async`, `await`, dan `Future` untuk operasi yang memerlukan jeda waktu.

Kesimpulan Praktikum:  
Pertemuan pertama ini memberikan pemahaman yang cukup jelas mengenai aturan sintaks dan logika pemrograman Dart. Hal ini menjadi bekal yang sangat penting sebelum melanjutkan ke pembuatan tampilan antarmuka (UI) dan pengembangan fitur aplikasi menggunakan Flutter pada pertemuan berikutnya.

Kesimpulan Praktikum:  
Pertemuan kedua memberikan pemahaman praktis mengenai dasar pembuatan antarmuka (UI) di Flutter, penerapan tata letak Column dan Row, pengelolaan form input dan navigasi antar halaman, serta penyajian data menggunakan ListView.
